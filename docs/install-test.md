# בדיקת התקנה של Condisco 0.2.0 (בערך 15 דקות)

מטרה: לבדוק שהתוסף עולה בחשבון ה-Pro שלך, ושהסקיל `study-setup` מצליח לפרסם את אפליקציית Condisco עם מסד נתונים פרטי.
Study Hub לא משתנה. הכול קורה בפרויקט זמני.

## שלבים
1. ב-claude.ai (דפדפן או אפליקציית מחשב): Settings > Capabilities, לוודא ש-Code execution פועל.
2. Customize > Plugins > Add > Upload plugin, ולבחור את `condisco-0.2.0.zip`.
   אם אין אפשרות להעלות תוסף: Customize > Skills > "+" > Upload a skill, ולהעלות את `study-setup.zip` בלבד.
3. ליצור פרויקט חדש בשם "Condisco test" ולפתוח בו צ'אט חדש.
4. לכתוב: `להתקין לי Condisco`
5. לענות על השאלות. מספיק בקצרה, עם קורס אחד לדוגמה.
6. בסוף Claude אמור לכתוב שורה אחת: `בדיקת db: עברה ✓` או `בדיקת db: נכשלה — ...`.
7. לפתוח את הארטיפקט "Condisco". בתחתית אמור להיות כתוב `שמירה: פעילה ✓ · סכמה 2`, והקורס שלך ברשימה.
