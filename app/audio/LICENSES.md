# Condisco recorded audio: sources and licences

Every file here is CC0, public domain or CC BY **for the recording itself**, not only the composition. Checked on Wikimedia Commons file pages (licence template in the page source) on 2026-11-26. Files were loudness-normalised (piano −20 LUFS, rain −24 LUFS), faded in/out and re-encoded to MP3 (piano 80 kbps stereo, rain 64 kbps mono). Only sea.mp3 (CC BY 3.0) legally requires attribution; the app credits every file under the sound picker ("מקורות ההקלטות").
